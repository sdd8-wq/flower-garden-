# flower-garden-
Simple 2d flower garden 
Project Description:
My project involves a simple 2d flower garden that was made in Godot. The main scene contains 3 flowers and butterfly. The different sizes of the flowers meant different directions the butterfly could go. 

What I learned: 
I learned ho to make a simple scene in godot it did take me a while but I added different sprites and images. I learned how to change positions and scales of the sprites I had. Also ran and tested a Godot project for the first time, which was cool because I’ve never done it before.
